# Xingyu Pan academic website

A responsive, build-free static website prepared for GitHub Pages.

## Preview locally

Open `index.html` directly, or serve this folder with any static web server.

## Publish with GitHub Pages

1. Create a GitHub repository (for a personal homepage, use `<username>.github.io`).
2. Upload all files and folders in this directory, preserving the `assets/` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After deployment completes, open the Pages URL and test navigation, the CV download, email link, advisor links, DOI, and responsive layout.
